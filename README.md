# TrialUnity

**Improving equity and transparency in clinical trial recruitment through AI.**

TrialUnity is a prototype health-tech platform designed to help both **researchers** and **patients** navigate clinical trial data more effectively. By combining machine learning with LLM-powered summarization, the system addresses two major gaps in clinical research: **diverse patient recruitment** and **usability of complex scientific data**.

---

## ✨ Features

### 🔹 Researcher-Facing
- **ESR Diversity Scoring**: Uses K-Means clustering in Python to generate ESR (SocioEconomic, Sex, Race) scores.  
- **Representative Cohort Selection**: Helps researchers form diverse, balanced patient pools to reduce bias in clinical trial results.  
- **Clustering Dashboard**: Provides insights into trial population representativeness through a Streamlit interface.

### 🔹 Patient-Facing
- **Smart Trial Search**: Connects to the [ClinicalTrials.gov API](https://clinicaltrials.gov/) to retrieve trial data.  
- **Data Cleaning Pipeline**: Processes and normalizes raw trial data using Pandas and NumPy.  
- **LLM Summarization**: Generates plain-language summaries of trials, making them easier for patients to understand.  
- **Personalized Recommendations**: Offers trial matches based on patient profiles and preferences.
